# Review HTML artifacts with Anno

Use Anno's MCP tools to start or resume a review session. After the user finishes reviewing, read the complete session, apply every accepted edit and annotation to the source HTML, validate the resulting standalone HTML, register the final artifact, and return it to the user.

Never treat the review UI as the final output. The final deliverable is the regenerated and registered HTML artifact.
